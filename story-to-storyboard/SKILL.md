# 绘本分镜生成

本文件仅规定编排层：入口、交付结构、执行顺序与校验。故事创作、绘图提示词、视频提示词各自的具体规则与模板原文，全部位于下列文件，本文件不承载其内容，亦不复述。

| 文件 | 负责内容 |
| --- | --- |
| `references/story.md` | 故事环节的全部规则与执行步骤，由该文件自行规定 |
| `references/creativity-path.md` | 可选创意路径（默认关闭）：接口契约与可替换的取值来源 |
| `references/drawing-prompt.md` | 绘图提示词环节的规则，含模板原文与绘图负面串（全技能唯一副本） |
| `references/video-prompt.md` | 视频提示词环节的规则，含视频负面串与成品句式（全技能唯一副本） |
| `references/voice-prompt.md` | 配音提示词环节的规则，含配音负面串、成品句式与三平台字段映射（全技能唯一副本） |
| `references/mcp-setup.md` | 绘图提示词优化的 MCP 配置指引，当前停用、不参与执行，仅在启用该能力时读取 |
| `references/example.md` | 成品格式对照样例，供脚本回归 |
| `scripts/pick_direction.py` | 创意路径所需的取值来源（可选） |
| `scripts/check_storyboard_md.py` | 以两份模板原文逐字比对成品 |

## 前置条件

绘本主题由用户提供，可为简单主题（仅主体与场景）或情节主题（已含诉求与阻碍）。主题缺失时按 `references/story.md` 处理候选来源并由用户选定；来源无结果时终止并索取主题，不得自行拟定，不得先行产出示例。

## 对外入口

| 触发输入 | 交付内容 |
| --- | --- |
| 一个绘本主题（如「月亮与小星星」） | 一组绘本分镜包，每组 6 行；组数默认值由 `references/story.md` 规定 |
| 未给出主题，且授权由技能选题 | 若干条候选主题（主题名、一句话方向、主体、环境），不直接产出分镜；选定后再按上一行交付 |

用户单独索要视频提示词或图生视频提示词时，以单句说明该内容属技能内部环节、不单独交付，并请用户提供绘本主题；主题提供后，视频提示词写入每组「→ 绘图提示词：」的下一行。不得为满足此类请求反向推导分镜。

## 交付结构（强制，不可改动）

每组严格 6 行，顺序固定：

```
【第 X 镜】
英文短句
→ 中文翻译
→ 绘图提示词：<按 references/drawing-prompt.md 的模板原文逐字填充>。负面：<同文件的绘图负面串>
→ 视频提示词：<按 references/video-prompt.md 的成品句式，末尾自带负面串>
→ 关键词：【color / size / action verb / place】
→ 配音提示词：<按 references/voice-prompt.md 的成品句式，末尾自带配音负面串>
```

五项强制约束：

- 英文短句独占第一行，不使用引号、括号注释或镜头说明。
- 绘图负面串置于绘图提示词同一行末尾，以「负面：」引出；不换行，不在套末汇总。
- 视频提示词紧随绘图提示词的下一行，压缩为一段，不带 ①②③ 标签，不单独成节。
- 关键词固定为第 5 行，四项顺序不变，每项对应本镜具体内容。
- 配音提示词固定为第 6 行即本组末行，朗读文本须与第 1 行英文短句逐字一致，参数写成可录入音频模型的字段。

文件级注记一条：在第一个「【第 X 镜】」之前写一行朗读预算（各组的视频秒数与预算秒数），供独立的语音模型对齐；该行属文件级注记，不插入任何组内，不改变每组的 6 行。

## 执行顺序

1. 按 `references/story.md` 完成故事环节，产出各组的英文短句与中文对译。
2. 按 `references/drawing-prompt.md` 完成绘图提示词环节，产出各组的绘图提示词行与关键词行。绘图优化当前关闭（见「外部能力：绘图提示词优化」），直接产出，不检测、不调用。
3. 按 `references/video-prompt.md` 完成视频提示词环节，产出各组的视频提示词行。
4. 按 `references/voice-prompt.md` 完成配音提示词环节，产出各组的配音提示词行。
5. 执行 `python scripts/check_storyboard_md.py <成品.md> --theme "<主题>"` 校验，错误须修正至通过。配音由独立语音模型后处理，不随视频直出；若已取得实测朗读秒数，以 `--voice-seconds "1:3.8,2:4.2"` 回填复校，超预算者先改短该句，不延长视频。

衔接要求：后一步以前一步的产物为依据；后续步骤与前一环节冲突时，回改前一环节，不得在后续步骤内强行自洽。脚本仅校验格式与模板一致性，语义是否紧扣英文短句由各 reference 的内容自检承担。

## 外部能力：绘图提示词优化（可选）

**当前状态：停用。** prompt-optimizer 尚未完善，默认运行中不检测、不询问、不配置、不调用，也不读取 `references/mcp-setup.md`；绘图提示词按 `references/drawing-prompt.md` 直接产出。以下各小节作为启用时待用的规则保留，除用户在对话中明确提出「启用绘图提示词优化」，一律不执行。

启用后，绘图提示词写完后可交由该 MCP 对**已填好四个槽位的成品文本**做一次措辞级优化。该 MCP 是后处理环节，不承担提示词生成：先理解句意、白话定画面、填槽位、拼模板、接负面串的既有逻辑原样执行，MCP 只在其后改写槽位内的文字。无论启用与否，绘图环节的产出方式不变，缺少它只是少一次润色，不是少一条生成路径。

该能力非必需，缺失或不可用时不阻断交付，也不得为了使用它而拖延或放弃产出。启用后，MCP 配置由当前 agent 在用户确认后执行：定位配置文件、备份、合并条目、校验写回，全部按 `references/mcp-setup.md`「由当前 agent 执行的配置步骤」进行。

### 调用契约（停用备查）

MCP 的输入只有一样东西：该组已经生成的绘图提示词。除此之外不携带任何上下文。

- **输入**：该组绘图提示词的完整文本，从模板起点「【画面比例】」起，到负面串结尾止。不加「→ 绘图提示词：」这类标签，不加组号，不加任何前后缀说明。
- **输出**：只采纳三个槽位内的文字。模板固定句与负面串仍以本技能原文为准，不采纳 MCP 返回的版本。
- **禁止携带**：绘本主题、英文短句与中文对译、关键词行、视频与配音行、其他组的内容、故事卡、风格要求、对话历史、技能规则。不得在提示词前后附加「请先理解这个故事」「这是儿童绘本」之类的背景说明，也不得把多组提示词合并成一次请求。
- **一次一组**：调用只处理当前这一组；上一组的返回文本不得拼入下一组的输入，避免跨组串味。
- **必填字段**：若工具 schema 另有必填字段，只填与「优化这段提示词」直接相关的中性值（如语言、任务类型），不得借该字段补传主题或故事内容。
- **不做往返**：一次调用一次采纳，不追加追问、不做多轮澄清；返回不可用即按「优化结果约束」回退。

### 执行前检测（停用备查，启用后于流程开始前执行一次）

检测在第 1 步之前完成，整轮只做一次，组内不再重复询问。

**获取 MCP 列表**：读取当前会话挂载的 MCP 服务与可用工具列表，确认是否存在 prompt-optimizer（`http://47.251.140.61:8081/mcp`）及其提供的工具。列表不可直接读取时，以 `prompt optimizer` 为关键词检索工具。判定以「服务存在且其工具可被调用」为准，不以对话里出现过 URL 为准，不得凭猜测虚构工具名。

| 检测结果 | 处置 |
| --- | --- |
| 已挂载 | 不询问、不提示安装，但须向用户明示本轮将调用该 MCP 优化绘图提示词（一行状态说明，不弹框），随后直接按「调用契约」使用 |
| 未挂载 | 以确认弹框询问是否需要安装，文案说明这是可选的绘图提示词二次优化能力、不安装不影响分镜产出。选项两档：立即配置、暂不配置 |
| 选择立即配置 | 读 `references/mcp-setup.md`，由当前 agent 按其「由当前 agent 执行的配置步骤」完成配置：确认客户端与配置文件位置、备份、合并条目、校验 JSON；随后重新读取 MCP 列表复检。复检通过即向用户明示「配置成功，后续将调用 prompt-optimizer 优化绘图提示词」，然后继续第 1 步，并在第 2 步启用优化 |
| 选择暂不配置 | 本轮不再提示，全程跳过优化，按原提示词交付 |

- 当前 agent 无写权限、找不到配置文件，或客户端要求重启才能识别：把该文件的配置提示词整段发给用户，说明需其执行或重启；本会话按未挂载继续，不等待、不阻塞，交付说明中注明。
- 拒绝只在本次会话内记忆，不写入长期偏好、不改动技能文件；下一轮执行时仍按本节重新检测、重新询问一次。
- 弹框能力不可用时以一条短问句替代，问题与两个选项不变。
- 用户选择立即配置但直到第 2 步仍未生效（未装成或未重启），不二次弹框，按未挂载继续，在交付说明中注明。

### 组内调用（停用备查，启用后在每个绘图行写成后执行）

- 每组绘图行写成后调用一次，传参按「调用契约」。
- **调用须可见**：不得静默调用。调用前输出一行状态，说明调用的对象与该组，例如「调用 prompt-optimizer MCP 优化第 3 组绘图提示词」；调用后输出一行结果，说明是否采纳（已采纳 / 已回退，附一句原因）。
- 调用成功：只提取三个槽位内的文字，按「优化结果约束」复核后写回该组绘图行；模板固定句与负面串仍以本技能原文为准。
- 调用失败、超时或返回空：最多重试一次；仍失败则跳过该组，标注「未优化（连接失败）」，流程继续。
- 组内不再询问用户，不重复确认配置，也不因单组失败回头重跑前一组。

### 优化结果约束

1. **只优化措辞，不重定画面。** 主体是谁、数量、姿态、朝向、互动关系、场景与光线均不得改变；允许的改动限于措辞、可见细节的精度与语序。不得把槽位写空、不得精简掉已有信息、不得扩写成第二件事。
2. **模板固定句逐字不变。** 从「，儿童绘本插画风格」至「柔和光影，无生硬阴影，低幼友好，画面不带内置文字、水印、签名」的原文不得增删改；仅三个槽位（画面主体、主体互动关系、环境场景）内的文字允许被改写。
3. **负面串不变。** 优化文本不包含「负面：」及其后内容，负面串仍由本技能在行末追加。
4. **事实约束不变。** 不得新增英文短句中不存在的角色、道具、场景；改写后仍须能被该句反推。
5. **脚本为准。** 优化后的该组须重新通过 `check_storyboard_md.py`；不通过即回退为该组优化前原文，并记录回退原因。
6. **下游以定稿为准。** 第 3 步视频提示词、第 4 步配音提示词均读优化后的绘图行；若优化改动了姿态或场景，须回头重写该组视频行，不得沿用优化前版本。

### 交付标注

停用时不作任何优化标注。启用后，交付说明写明哪些组经 MCP 优化、哪些组跳过及其原因（未配置、用户拒绝、连接失败）。两种情况成品行内都不写标记，不改动 6 行结构。

## 产物与加载约定

本技能的上下文开销主要由两件事决定：是否把整份 reference 反复读入，以及中间结果是否只存在于对话里。两条都须约束。

### 1. 产物约定

一个成品 Markdown 是贯穿全流程的唯一累积载体，各步骤只写自己那一段，下游只读产物，不复述上游内容。

| 步骤 | 产物 | 载体 |
| --- | --- | --- |
| 1 故事 | 故事卡：主体清单、环境、诉求、阻碍、解决、结局；每组一句英文与中文对译 | 成品文件的组标题与前三行 |
| 2 绘图 | 每组绘图提示词行（含负面串）、关键词行 | 同一文件，逐组追加 |
| 3 视频 | 每组视频提示词行（含负面串）；文件头的朗读预算行 | 同一文件，插入该组绘图行之后；预算行只在第 1 组之前写一次 |
| 4 配音 | 每组配音提示词行（含负面串） | 同一文件，追加于该组关键词行之后 |
| 5 校验 | 脚本输出 | 命令回显，不落盘 |

- 逐组推进：完成一组再进入下一组，不得先把六组句子全部写出再回头补提示词。
- 中间内容写入产物文件或对话中的分组块后，不再重述；回改时只改该段，不整份重写。
- 产物文件默认置于与技能目录同级的 `output` 目录，即 `<技能目录>/../output/`；命名为《主题》-分镜与提示词.md。目录不存在时创建；用户明确指定输出路径时，以用户指定为准。

### 2. 加载约定

按步骤读取所需片段，不整份加载；已读内容不重复读，模板原文只在书写时引用，不在回复中复述。

| 步骤 | 必读 | 按需读 | 不读 |
| --- | --- | --- | --- |
| 1 故事 | `story.md` 第二、五、六、七、八、九节 | 第一节创意原则、第三节三问（自检时）；启用创意路径时改读 `creativity-path.md` | 第十节删除记录；未启用时的 `creativity-path.md` |
| 2 绘图 | `drawing-prompt.md` 的模板原文、绘图负面串、槽位对照、拼行规则 | 出图顺序（仅用户要求出图时）；崩坏修法（仅返工时） | 来源说明段；`mcp-setup.md`（优化停用时不读） |
| 3 视频 | `video-prompt.md` 的成品形态、语言时长与画面余量、两步理解、五维细则 | 动作词表（只读与主体类型匹配的一段）；自检表（首次使用或不合格时） | 示例 A/B（格式已掌握后） |
| 4 配音 | `voice-prompt.md` 的成品形态、参数口径、四要素写法 | 平台字段映射（换平台时）；自检表（首次使用或不合格时） | 示例（格式已掌握后） |
| 5 校验 | 校验命令 | `example.md`（仅格式回归时，且只对照句式） | 其余全部 |

- `example.md` 默认不读；格式已由本文件的交付结构定义，无需借样例确认排版。
- 六组共用一个模板与一套负面串，只需读取一次；写第 2 至 6 组时不得再次加载同一文件。
- 若上下文不足以容纳全部产物，以产物文件为准，按其内容续写，不重新生成已完成的组。

## 引用纪律

- 模板原文、绘图负面串、视频负面串、配音负面串各仅有单一副本，位于对应 reference 文件；出现于其他文件时视为错误。
- 填充时整段复制后替换槽位，不得重组句式，不得省略分号分隔的任何固定短句。
- 模板固定句与既定口径冲突时，以模板为准；需调整口径时修改模板文件本身，并同步执行校验。
- 配音的音色、音高、音量在六组间保持一致，仅情绪与重音随句变化；换用其他音频平台时按 `voice-prompt.md` 的映射表折算，不改变字段语义。

## 交付方式

- 于对话中直接输出完整内容（组数按 `references/story.md`，每组 6 行），不提供摘要替代。
- 用户要求文件时，默认将 Markdown 写入与技能目录同级的 `output` 目录，命名为《主题》-分镜与提示词.md，并执行校验脚本；用户明确指定路径时除外。
