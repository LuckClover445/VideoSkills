# 绘图提示词

**来源说明**：本文件里的「模板原文」与「绘图负面串」是给定的原文，**是全技能唯一副本**，只能逐字使用，不得改写、不得精简、不得在别处另抄一份。槽位填法、关键词写法、出图顺序、崩坏修法是补充规则。

**阅读指引**：书写时只读「模板原文」「绘图负面串」「槽位对照」「拼成一整行」四节；「出图顺序」仅在用户要求出图时读；「崩坏修法」仅在返工时读。整套六组共用同一模板与同一负面串，只读一次。

## 模板原文（逐字使用）

> 【画面比例】，儿童绘本插画风格，蜡笔彩铅卡通风格，可爱，造型圆润简单，色彩鲜亮柔和，整体画面带有蜡笔质感和笔触，清晰可见纸张纹理，氛围童趣温馨；强烈蜡笔、彩铅质感，笔触方向清晰，带有颗粒纸面摩擦效果、斑驳填色，不是纯平涂；背景植被使用短促重复 scribble 随手画笔触，【画面主体】，【主体互动关系】，【环境场景】，柔和光影，无生硬阴影，低幼友好，画面不带内置文字、水印、签名

## 绘图负面串（逐字使用，唯一副本）

> 纯平涂，光滑无笔触，写实照片，3D渲染，皮克斯风格，赛璐璐上色，阴暗压抑，恐怖，畸形，五官崩坏，模糊，画面杂乱，多余肢体，自带文字，水印，签名

## 先理解句意，再定画面，最后才入模板

绘图提示词不是从主题想象出来的，是从这一组的英文短句读出来的。顺序不能倒；但读，不是拆主谓宾。

### 第一步：判断这句话在说什么

先归类，再决定画里谁是主角：

| 这句话的类型 | 例 | 这一镜必须成立的那件事 |
| --- | --- | --- |
| 谁在做什么 | A little star peeks out from behind a cloud. | 星星露出半个身子，云被顶开一角 |
| 环境里正在发生什么 | It is raining. / The night grows quiet. | 雨在落、地面在湿；夜色转静、草尖不再摇 |
| 一个东西在怎么变 | The bud opens. / The cup tips over. | 花苞张开、杯子倾倒并流出水 |
| 只是一层氛围 | Everything is still. | 静止：无风、无晃动、光稳定 |

**很多句子没有明确指向某个角色。** 这时不要硬找出一个主角塞进「画面主体」。句子说下雨，主体就是雨和被打湿的地面；句子说夜很静，主体就是夜色、草与光。选出来的具体主体只要与本句语义一致、与整套的既有主体不冲突即可。

### 第二步：先用一句白话把画面说出来

动笔写模板之前，先在心里（或草稿上）说清这一镜到底长什么样，例如：

> 画面左侧三分之一，一颗圆胖浅黄的星星从云背后露出半个身子，云的交界处被顶开一道口子；深蓝夜空，远处两点小星；光从左上来，云边有一圈亮边。

这句白话就是这一镜的画面。它必须只靠英文句就能成立，不许出现句子没有的角色、道具、第二件事。

### 第三步：把这段画面写进四个槽位

四个槽位是**装画面的容器**，不是输入清单。不要拿着"谁/做什么/在哪"的词往四个格子里各放一个词——那样会写出四个互不相干的碎片。

正确做法是：把第二步那段白话按「比例 / 主体 / 互动 / 环境」重新分配——

| 槽位 | 承接画面里的什么 |
| --- | --- |
| 画面比例 | 只放比例值 |
| 画面主体 | 主体是谁或什么 + 外形 + 颜色 + 此刻姿态 + 朝向 + 画面占比 |
| 主体互动关系 | 主体之间或主体与道具/环境的接触关系，定格在动作那一瞬，并写可见结果 |
| 环境场景 | 地点 + 时间 + 天气光线 + 支撑主体的背景层次 |

同一个元素可以在两个槽位各出现一次侧重（星星在「主体」写外形，在「互动」写它怎么顶云），但不要只是复读同一句。

**可以补的**：画得出来的外观细节——材质、数量、朝向、颜色深浅、光从哪来、投影多长、地面的质感。
**不可以补的**：句子里没有的角色、道具、第二件事、文字、旁白式叙事、镜头语言（镜头/景别/推拉摇移都不属于绘图提示词）。

判断标准只有一条：**遮住英文句，只看提示词，能不能反推出同一句话**。推不出来的多余内容，删掉；反推不出来的空洞槽位，回去补画面。

## 四个槽位怎么填

顺序与位置固定，只替换方括号里的内容：

| 槽位 | 填什么 | 合格 | 不合格 |
| --- | --- | --- | --- |
| 画面比例 | `16:9` / `9:16` / `1:1` / `4:3`，用户指定优先，未指定用 16:9 | 16:9 | 竖屏 |
| 画面主体 | 主体 + 外形 + 颜色 + 姿态 | 一只圆胖的浅黄色小星星，五角圆润，脸颊两团橘粉腮红，探出半个身体 | 小星星 |
| 主体互动关系 | 主体之间、主体与道具的接触和动作 | 躺在月牙背上，一只小手抓住月亮的尖端 | 很开心 |
| 环境场景 | 地点 + 时间 + 天气光线，大背景放这里 | 深蓝夜空，远处三朵薄云，草地边缘泛着月光 | 夜晚 |

槽位里只写画得出来的：颜色、形状、大小、材质、姿态、朝向、数量、光的方向。不写「温暖的」「梦幻的」这类成品评价。

## 拼成一整行

填完四个槽位，在句末接绘图负面串，整行就是可直接投喂的绘图提示词：

```
→ 绘图提示词：【16:9】，儿童绘本插画风格，……低幼友好，画面不带内置文字、水印、签名。负面：纯平涂，光滑无笔触，写实照片，3D渲染，皮克斯风格，赛璐璐上色，阴暗压抑，恐怖，畸形，五官崩坏，模糊，画面杂乱，多余肢体，自带文字，水印，签名
```

负面串与提示词同一行，用「负面：」引出；不换行、不单独成段、不在套末汇总；每组都要带。

## 关键词行

```
→ 关键词：【color / size / action verb / place】
```

四项固定顺序，都落到本镜具体内容：

```
→ 关键词：【color = 浅黄 + 深蓝｜size = 画面右下三分之一｜action verb = 探出｜place = 云朵边缘】
```

- color：主体主色 + 背景主色。
- size：相对大小或数量（手掌大小 / 占右下三分之一 / 五颗）。
- action verb：一个动词，必须是本镜主体真在做的，和英文句的谓语对得上。
- place：具体位置或场所，不写「外面」。

四项凑不齐，说明这一镜的画面没想清楚，回去改句子。

## 出图顺序（用户明确要图时才执行）

1. 先出第 1 镜，确认画风、纸张纹理、主体造型。
2. 以第 1 镜为参考图，按顺序出 2-6 镜，每镜只改姿态、互动、场景细节。
3. 哪一镜风格不一致，单独重出那一镜，不要重出整组。
4. 全部出齐后横向对比主体比例与配色，有偏差的修正主体槽位再重出。

默认不生图。出图失败就保留提示词并说明，不许改模板措辞去迁就模型。

## 常见崩坏与改法

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 出来是平涂卡通 | 模板里的质感短句被简化或删掉 | 恢复「强烈蜡笔、彩铅质感……不是纯平涂」整段，一字不改 |
| 背景变成渐变 | 环境槽位只写了「夜空」 | 补地点细节与薄云/树影 |
| 两镜之间主体变形 | 主体槽位每镜重写得不一样 | 主体描述套内固定，只改姿态与互动 |
| 画面出现花体字 | 主体槽位里写了「写着 XXX 的牌子」 | 改为「一块空白的木牌」 |
| 质感像 3D 渲染 | 正文混入 3D/皮克斯/赛璐璐 | 正文删掉，只让这些词留在负面串里 |
| 颗粒被磨平 | 模型偏好平滑输出 | 保留「颗粒纸面摩擦效果、斑驳填色」，必要时重复一次「蜡笔、彩铅笔触，可见纸张颗粒」 |

## 比例适配

| 比例 | 追加写法 |
| --- | --- |
| 9:16 | 主体居中偏上，上下留白，纵向构图 |
| 16:9 | 主体占左或右三分之一，另一侧留给环境 |
| 1:1 | 主体居中，四周等距留白 |
| 4:3 | 主体居中，背景层次前后分明 |

只改第一个方括号，模板其余部分不动。
