# 配音提示词规范（每组一行，第 6 行）

**阅读指引**：书写时读「成品形态」「参数口径」「四要素写法」；「平台字段映射」按实际使用的平台查一列；「示例」与「自检」在首次使用或返工时读。配音负面串与成品句式在本文件各仅有一份，勿在他处复述。

## 成品形态

成品占每组最后一行，紧跟关键词行之后：

```
→ 配音提示词：朗读文本 "<英文原句>"；模型 seed-audio-1.0；speaker <音色ID>；speech_rate <-50 至 100 的整数>；pitch_rate <-12 至 12 的整数>；loudness_rate <-50 至 100 的整数>；句末静音 <毫秒>；情绪 <一词>；指令 <一句朗读指令>。负面：<配音负面串>
```

`朗读文本` 必须与第 1 行的英文短句逐字相同，含标点；不得改写、缩写或补词。整行为一段，不换行、不分维度标签、不另起小节。

## 配音负面串（逐字使用，唯一副本）

> 负面：急促赶读，念白腔，机械平调，旁白解说，添加拟声词，压缩句末停顿，改变句末词，音量忽大忽小

## 参数口径（以火山引擎 seed-audio-1.0 为准）

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `model` | `seed-audio-1.0` | 豆包语音音频生成模型；若改用旧版接口，换成 `voice_type` + `speed_ratio` 一组 |
| `speaker` | 控制台音色 ID | 全系列六个分镜必须同一音色，不得逐组更换 |
| `speech_rate` | -50 至 100，整数 | 0 为原速；-50 为 0.5 倍，100 为 2 倍。默认 0，需提速时按 +10 一档递增 |
| `pitch_rate` | -12 至 12，整数 | 0 不调整。儿童向取 0 至 +2，不得靠拉高音调伪装童声 |
| `loudness_rate` | -50 至 100，整数 | 0 不调整。六组保持一致，避免响度跳变 |
| 句末静音 | 250 至 500 毫秒 | 与视频收势余量配合；不得为 0（会切断句尾音） |
| `enable_subtitle` | `true` | 便于取回逐句时间戳，回填 `--voice-seconds` 的实测值 |
| 输出格式 | `wav` 或 `mp3`，24000 或 44100 Hz | 与后续剪辑时间线一致即可 |

## 平台字段映射

| 语义 | 火山引擎 seed-audio-1.0 | 火山引擎旧版 | MiniMax speech-02 | ElevenLabs | OpenAI gpt-4o-mini-tts |
| --- | --- | --- | --- | --- | --- |
| 音色 | `speaker` | `voice_type` | `voice_id` | `voice_id` | `voice`（alloy/ash/coral/echo/fable/onyx/nova/sage/shimmer） |
| 语速 | `speech_rate` -50~100 | `speed_ratio` 0.2~3 | `speed` 0.5~2 | `speed` 0.7~1.2 | `speed` 0.25~4.0 |
| 音高 | `pitch_rate` -12~12 | `pitch_ratio` 0.1~3 | `pitch` -12~12 | 无独立字段，用 `style` 旁调 | 无独立字段，用 `instructions` 描述 |
| 音量 | `loudness_rate` -50~100 | `volume_ratio` 0.1~3 | `vol` 0~10 | 无独立字段 | 无独立字段 |
| 情绪 | 写进 `text_prompt` 的自然语言 | `emotion` | `emotion`：happy/sad/angry/fearful/disgusted/surprised/neutral | `stability` 0~1、`style` 0~1 | 写进 `instructions` |
| 句末停顿 | 标点或 `text_prompt` 描述 | `silence_duration` 毫秒 | 标点控制 | 标点控制 | 标点或 `instructions` |
| 时长回取 | 响应 `duration` / `subtitle` | 响应 `addition.duration` | 响应 `duration` | 响应 `audio_duration` | 响应 `duration` |

换平台时只映射上表，`speaker`、`speech_rate`、`pitch_rate`、`loudness_rate` 四项名称不变的部分保留原值，变动部分按该平台取值范围折算，不得把 -50~100 的取值直接写进 0.5~2 的字段。

## 四要素写法（一行内，顺序固定）

**① 朗读文本**：英文原句逐字照抄，含句号。句子多词时不做重音标注以外的任何改动。

**② 音色与参数**：`speaker` 写音色 ID 或「温暖童声（女，8-10 岁感）」这类可检索描述；`speech_rate` 默认 0；`pitch_rate` 0 至 +2；`loudness_rate` 与全系列一致。

**③ 情绪与重音**：情绪取一个词，限定为可听出来的叙事语气——期待、雀跃、安静、迟疑、俏皮。不得写「很感人」「治愈」这类成品评价。重音落在句子里承担语义的那个词上（如 `peeks`、`too wide`、`catch`），一句只标一处。

**④ 停顿与预算**：写出本组预算（5 秒容器为 4.3 秒）；句末静音 300 毫秒为常用值。指令里写明「不加速」「句末轻上扬」这类可执行要求，并说明预算内读不完时先改短句子。

## 与视频时长的关系

配音迁就视频，不反向回改视频。原速读不完 4.3 秒时，按序处理：

1. 提高 `speech_rate`，每档 +10，上限 +30（约 1.15 倍）；ElevenLabs 上限 1.2，OpenAI 上限 4.0 但儿童向不建议超过 1.2。
2. 压缩句末静音至 250 毫秒，不得低于此值。
3. 仍读不完，回 `story.md` 第八节改短该句，不延长视频。

## 示例

> → 配音提示词：朗读文本 "A little star peeks out from a cloud."；模型 seed-audio-1.0；speaker 温暖童声（女，8-10 岁感）；speech_rate 0；pitch_rate 1；loudness_rate 0；句末静音 300ms；情绪 期待；指令 以讲故事口吻朗读，peeks 稍重读，句末轻上扬，预算 4.3 秒内读完，不加速。负面：急促赶读，念白腔，机械平调，旁白解说，添加拟声词，压缩句末停顿，改变句末词，音量忽大忽小

> → 配音提示词：朗读文本 "The cloud gap is too wide to cross."；模型 seed-audio-1.0；speaker 温暖童声（女，8-10 岁感）；speech_rate 10；pitch_rate 1；loudness_rate 0；句末静音 300ms；情绪 迟疑；指令 语速略提一档，too wide 稍拉长，句末下沉收住，不拖尾。负面：急促赶读，念白腔，机械平调，旁白解说，添加拟声词，压缩句末停顿，改变句末词，音量忽大忽小

## 常见错与改法

| 错法 | 问题 | 改法 |
| --- | --- | --- |
| 朗读文本改写原句（删冠词、换词） | 与画面字幕、视频动作对不上 | 逐字照抄第 1 行 |
| 每组换音色 | 六组像六个人读 | `speaker`、`pitch_rate`、`loudness_rate` 全系列锁定 |
| 情绪写「温暖治愈」 | 无法转成可听参数 | 换成期待/安静/迟疑等单一语气 |
| 直接写 `speech_rate 0.9` | 该字段是 -50~100 的整数 | 写 0，或写 -10 表示略慢 |
| 静音设 0 | 句尾音被切断 | 250 至 500 毫秒 |
| 全篇标重音 | 等于没有重音 | 一句只标一处 |

## 自检

A 朗读文本是否与第 1 行英文短句逐字一致，含标点？
B `speaker`、`pitch_rate`、`loudness_rate` 是否六组一致？
C `speech_rate` 是否在 -50 至 100 的整数范围内，且未超过 +30？
D 情绪是否为单一可听语气词，重音是否只标一处？
E 句末静音是否在 250 至 500 毫秒之间？
F 是否写出预算秒数，且明确「读不完先改句」而非加速到失真？
G 负面串是否与本文件原文逐字一致？
