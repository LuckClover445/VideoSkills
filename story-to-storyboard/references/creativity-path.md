# 创意路径（可选旁路，默认关闭）

本文件是 `story.md` 的可选前置环节，不属于默认流程。核心路径（主题约束 → 收敛故事 → 拆组 → 写句 → 主体连贯）确定性强，同一主题重复生成结果一致；创意路径用于在保持主题主体的前提下，换取不同的讲述方式与骨架。

## 一、启用条件

满足任一条件方可启用：

- 用户明确要求"每次不一样""换个讲法""给几个方向""不要和上次一样"。
- 同一主题第二次生成，且用户表达了求变意图。

未满足时不得调用任何抽取动作，不得打印方向，不得写入历史。默认关闭不是能力缺失，而是确定性优先：用户未要求的变体一律视为风险。

## 二、接口契约（替换实现只改来源，不改契约）

输入：主题原文、主题主体清单、主题已写明或可推出的环境。

输出（内部使用，不对外展示，逐行文本）：

```
呈现变量｜叙事视角=…｜意象承载=…｜情绪基调=…｜结构变体=…｜转折类型=…
前提要素｜主角处境=…｜背景变体=…｜小麻烦=…｜转折点=…｜结局=…
指纹｜<以上全部取值的拼装串>
近期已用｜<最近 8 条的情景、动作、节拍>
```

硬约束（任何实现都不得违反）：

- 不得替换主题主体，不得给出与主题环境不相容的背景。
- 前提要素必须写成关系模板，不得写成具体名词；例：「一个总差一步的距离」，不得写「一口深井」。
- 指纹不得与最近 8 条记录重复；条目缺失时按「无禁止项」处理。
- 输出只作内部约束，不得把变量名或其取值写进成品。

## 三、实现方式（可替换）

| 实现 | 适用 | 状态 |
| --- | --- | --- |
| 本地随机：`python scripts/pick_direction.py` | 离线、快速、无网络依赖 | 已实现 |
| 联网检索 | 从公开故事与绘本的结构摘要中取骨架，只取结构与节奏，不取角色、专名与原文句 | 待接 |
| 自建知识库检索（RAG） | 从本地绘本结构库检索未用过的骨架，按主题环境过滤 | 待接 |

接入方式：新增实现只替换第二节契约中的"取值来源"，其余步骤（冲突过滤、去重、记录、质量门槛）原样复用。文件名与调用命令须写在本节表格内，不得散落在其他文件。

候选条目的组织方式参照模块化前提合成：把前提拆成若干模块，每模块建候选库，按依赖顺序取一条路径，再合成为一句连贯前提。对本技能而言，模块与本文件的关系是：

| 模块 | 是否可抽 | 说明 |
| --- | --- | --- |
| 主题 | 不可抽 | 用户给定，见 `story.md` 第二节 |
| 主角 | 不可抽 | 即主题主体，只抽「主角处境」 |
| 背景 | 可抽，限主题环境内 | 时间、天气、光线角度 |
| 事件 | 可抽 | 小麻烦，须为关系模板 |
| 结局 | 可抽 | 闭合方式，须为关系模板 |
| 转折 | 可抽 | 兼作「转折类型」 |

## 四、抽取内容

呈现变量五维（只决定怎么讲）：

| 维度 | 取值 |
| --- | --- |
| 叙事视角 | 主角自述、旁观者、被帮助者、物件视角、群体视角、归来者视角、误入者视角 |
| 意象承载 | 主体本身、主体的一部分、主体的影子或痕迹、主体带来的光或天气、与主体交换位置的对象 |
| 情绪基调 | 温暖、雀跃、安静、悬念、俏皮、克制、期待 |
| 结构变体 | 线性推进、重复累积、误会解开、交换与归还、追逐与躲藏、一夜之间、由远及近 |
| 转折类型 | 认知反转、身份反转、方向反转、大小反转、时间反转、因果反转 |

前提要素五维（只决定骨架），条目须写成不含专名的关系模板：

| 维度 | 示例条目 |
| --- | --- |
| 主角处境 | 被落下、够不到、怕黑、想加入、只剩自己、多出来一个 |
| 背景变体 | 天刚暗、夜深、天色将亮、起风、落一层薄雾 |
| 小麻烦 | 一个总差一步的距离、一个会在关键时熄灭的光、一个装不下的容器、一个不肯让路的东西 |
| 转折点 | 发现对方一直在等、办法反着用才成、位置互换后各自合适 |
| 结局 | 回到原位、距离被缩短、误解变成共识、多出的一样东西被留下 |

## 五、冲突过滤与重抽

抽取结果与主题主体冲突时，丢弃该条重抽，不得为迁就变量而改主题。判据只有一条：抽完之后，主题主体是否仍是画面的主角。

前提要素之间亦须自洽：结局不得否定小麻烦的存在，转折点须发生在小麻烦之后。

## 六、去重与记录

各维避开上一次的取值，相邻两套逐维不同；完整指纹记入 `assets/direction-history.json`（保留最近 8 条），与任一条完全相同则重抽。`--dry-run` 只打印、不写历史。

重复请求时重新抽取，主体不变。

## 七、近期情景、动作、节拍的显性禁止

维度不重复，不等于故事不重复：同一套五维可以写出情节雷同的两套故事。抽取输出的「近期已用」清单即本套的禁止清单，逐条对照：

| 项 | 定义 | 判为复用 |
| --- | --- | --- |
| 情景 | 场景与冲突的一句话概括 | 同一场景配同一冲突，或只更换角色而冲突不变 |
| 动作 | 全套主动作序列（三至四个关键动作） | 关键动作先后顺序相同 |
| 节拍 | 成败或情绪的节奏型 | 节奏型相同，即使换掉事件 |

- 任一项命中即重抽并重写故事；换近义词或换角色复述同样算复用。
- 历史为空时不设禁止项，仍须记录本套，使下一次有据可依。
- 单套之内六组亦不得重复同一动作，除非本镜明确写它在推进（退回、再试、换手）。

成品完成后记录：

```
python scripts/pick_direction.py --log "<主题>|<情景>|<动作>|<节拍>"
```

## 八、质量门槛

启用创意路径的成品，除 `story.md` 的既有自检外，还须满足：

1. 主题主体按原词出现在成品（`check_storyboard_md.py --theme "<主题>"` 通过）。
2. 主角处境、小麻烦、结局三者能串成一条因果链，不得并列罗列。
3. 核心意象由主题主体承担，抽掉后故事不成立。
4. 六组之间为推进关系，不为同一骨架的重复演示。

任一条不满足，回到第五节重抽或回到 `story.md` 第六节重写。
