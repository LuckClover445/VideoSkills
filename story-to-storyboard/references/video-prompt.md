# 视频提示词

**来源说明**：五个维度的定义、按主体类型的动作词表、情绪与植物器物规则、自检 A-F、示例均为给定原文；「成品句式」与「长度控制」是补充规则（给定模板只说了每镜 120-200 字、粘贴版 ≤ 260 字）。本文件里的「视频负面串」是全技能唯一副本。

**阅读指引**：书写时读「成品形态」「语言时长与画面余量」「两步理解」「五维细则」「硬规则」；「动作词表」只读与主体类型匹配的一段（人物 / 动物 / 植物 / 器物 / 环境）；「示例 A、B」与「自检」在首次使用或返工时读。同一组模板由六组共用，负面串只读一次。

## 成品形态

成品只占分镜包里的一行，紧跟「→ 绘图提示词：」之后：

```
→ 视频提示词：以首帧为准，<比例>，<秒数>。<主体姿态与主动作：方向、幅度、次数或节拍、用时>。<副动作与环境回应>。<镜头运动与起幅落幅>。保持<质感与一致性项>。负面：<固定串>
```

①-⑤ 是动笔前的思考顺序与自检项，不写进成品、不带标签、不换行、不另起段落。

## 语言时长与画面余量（写动作前先算一遍）

配音不随视频直出，由独立的语音模型后处理。因此对齐方向固定为：**视频是容器，配音迁就视频**。视频时长由画面节奏决定，不因配音偏长而重生成——重做视频的成本高于改写一句或调一次语速。

**预算** = 视频时长 − 0.7 秒收势余量。5 秒容器下每组朗读须 ≤ 4.3 秒；8 秒容器下 ≤ 7.3 秒。

**预检折算**（成品尚无实测时使用）：每词 0.4 秒，句末停顿 0.5 秒。据此 5 秒容器内的英文句上限为 8 词：8 词折算 3.7 秒，距预算尚余 0.6 秒，留给配音的自然起伏；4 词折算 2.1 秒，余量最宽。

**以实测为准**。配音生成后若拿到实测时长，用 `--voice-seconds` 回填校验（形如 `1:3.8,2:4.2`）。实测或折算超出预算时，按序处理：

1. 改短该句（删修饰语、删第二个动作、改为单动作）——首选，视频不动。
2. 与配音侧调快语速或压短句末停顿——次选，须确认不损伤儿童向的自然节奏。
3. 延长视频——最后手段，仅限原文允许范围（默认 5 秒，生长或累积类 8 秒），并重跑校验。

**三条硬约束**：

1. **动作总和不得超过预算。** 8 词句的全部主动作须在 3.7 秒内完成，不得拖到第 5 秒；4 词句须在 2.1 秒内完成。
2. **语义落点须早于朗读结束。** 关键词所指的动作完成点，早于朗读结束不得少于 0.3 秒，使观众听到最后一个词时画面已把这句话做完。
3. **朗读结束后保留 ≥ 0.7 秒收势与定格。** 这段时间画面仍在动，停下的是叙事而非画面：轻微回弹、光稳定、呼吸起伏可继续，不得整幅静止。

**写法**：④ 节奏里把预算写出来，形如「5 秒。预算 4.3 秒，折算朗读 3.7 秒；主动作 0–3.2s，3.2–5s 收势」。这句预算写进内部核对，不写进成品行。

## 两步理解（顺序不能倒）

视频提示词的输入是「首帧插画 + 英文短句」，而首帧插画就是上一行绘图提示词画出来的东西。所以写之前必须回头读那行绘图提示词。

**第一步：读绘图提示词，还原首帧。** 从中读出四件事——主体是谁、几个；在哪、什么姿态、朝向哪边；手边有什么道具、道具在哪个位置；光从哪来、场景是什么质感。这四件事决定 ① 主体与 ⑤ 统一性。

**第二步：读英文短句，定这一镜唯一要成立的动作。** 这句话只允许一个动作结论：句子说的是「探出」，画面就只成立「探出」，不许顺带「飘走」「回头看」。动作要能从第一步的姿态接上去（首帧躺着，就只能从躺起）。这一步决定 ② 动作、③ 效果、④ 节奏。

句子没有明确主体时（`It is raining.`、`The night grows quiet.`），动作即环境自身的状态变化：雨丝斜落、水洼扩大、草停止摇摆、光逐渐稳定。不得为补足动作主体而虚构角色。

两条禁止：

- 不得引入绘图提示词里没有的角色、道具、场景。视频是在首帧上做运动，不是重画一帧。
- 不得把句子没写的结果加进去。句子只说「顶开一角」，不能写成「整朵云散开」。

首帧读错了（姿态根本接不上这句话），回去改绘图提示词，再重写视频；不要在视频里硬接。

## 视频负面串（逐字使用，唯一副本）

> 负面：纯平涂，光滑无笔触，写实照片，3D渲染，皮克斯风格，赛璐璐上色，镜头剧烈晃动，主体变形换装，多长手脚，手指与五官畸变，画面杂乱，出现文字水印签名。

每组视频行末尾自带这条串，不再有额外的汇总负面段。整行 ≤ 260 字，超了先删副动作与环境回应，不要删主动作的四要素。

## ① 主体

先判类型：人物 / 动物 / 植物 / 器物 / 环境元素。再写：

- 主体一：承担句意主动作的那个（占画面左/右/中，占比多少）。
- 主体二：只做被引发的反应，不许抢主动作；没有就写「无」。
- 数量、朝向（朝左 / 朝右 / 背对）、首帧当前姿态（站 / 蹲 / 跪 / 飞 / 生长中 / 放置中）。

关键：动作必须从首帧姿态接上去，不得从零重设姿态。首帧如果是躺着，这一镜就只能从躺起。

## ② 动作

一条主动作 + 1~2 条副动作 + 1 条环境被动回应。

主动作必须拆到身体部位，每个动作写全四要素：**方向、幅度、次数或节拍、速度（完成用时）**。

- 合格：「右臂抬至肩高，小臂左右摆两下，用时约 1 秒」
- 不合格：「挥手」（缺方向、幅度、次数、速度）
- 不合格：「右手抬起」（只有部位和结果，没有过程）

## ③ 效果

至少写三类，写可观察的结果，不写抽象评价：

| 类别 | 写什么 |
| --- | --- |
| 位移或形变 | 间距缩短半步、叶面卷起、影子拉长 |
| 物理反馈 | 挤压、弹跳、承重下沉、摩擦、反作用力、回弹 |
| 光影变化 | 高光移动、影长变化、色温变化 |
| 情绪外化 | 起始神态 → 结束神态 |
| 语义可读 | 单看这一帧能否读出这句英文的意思 |

## ④ 节奏

- 总时长默认 5 秒；生长、累积类可 8 秒。
- 三段节拍：0-1s 起势、1-3.5s 主动作、3.5-5s 收势或停留。
- 动作次数折算用时：两下 ≈ 0.8s、三下 ≈ 1.2s（补充规则）。
- 关键瞬间放慢，例如落下接触地面的那一格。
- 镜头给机位与运动：固定 / 缓推 / 缓拉 / 横移跟拍，写明起幅与落幅（起幅全景、落幅中景），一镜只允许一个运动。
- 与朗读配套时标出关键词落点秒数（`关键词 meet 落在 3.5s`）。

## ⑤ 统一性

逐项与首帧对齐：画风与笔触、纸张纹理、主体比例与五官风格、服装与配色、场景布局与道具位置、光线基调。同时声明：不新增角色、不改服装、不换场景、不出现文字水印、系列内所有分镜镜头语言与时长同档。

## 硬规则（给定原文）

- 情绪不写抽象词：「开心」改写为「嘴角张开露出牙齿、眼睛弯成月牙、眉毛抬起」；「惊讶」改写为「眼睛睁大、嘴张成 O 形、身体后仰半寸」。
- 植物与器物没有表情，用形态变化与光影替代情绪，不得给它写五官动作。
- 每个分镜只回答那一句的含义，不要把相邻分镜的动作带进来。
- 时间只往前走，不写「先闪回」「来回切换」。
- 长度控制在每分镜 120-200 字，粘贴版一段不超过 260 字。
- 不使用「电影级」「超清 4K」「极致」等空泛词，全部用可见动作与物理描述替代。

## 动作词表（按主体类型换用）

**人物**：头（转向 / 倾仰 / 点头）｜表情（眉、眼、嘴、脸颊、呼吸）｜手（左右分工、抓握、张开、挥动、支撑、手腕角度）｜腿（站蹲跪跑踮、重心转移、落脚顺序）｜躯干（前倾、后仰、扭转、肩头起伏）｜连带（裙摆、辫子、衣角）

**动物**：头｜耳（竖起 / 后贴 / 抖动）｜眼｜口鼻（张口、嗅、吐舌、咀嚼）｜翅鳍尾（扇动频率与轨迹）｜四肢（爪着地、抬爪、跃起落地缓冲）｜躯干（弓背、毛发羽毛起伏）｜群体（跟随、挤靠、队形变化）

**植物**：株高（抽长 / 矮缩 / 倾斜）｜茎（弧度、抖颤）｜叶（开合、翻转、随风向）｜花（花苞鼓胀、花瓣张开角度、花盘转向）｜果（膨大、上色、摆动、落地）｜根与土（隆起、裂缝）｜生长节律（匀速、顿挫、受压回弹）

**器物**：位置与位移路径、倾角｜形变（压痕、褶皱、膨胀、弯曲）｜受光（高光移动、影长）｜被作用方式（推、拉、碰、装填）｜内容物（液面晃动、颗粒流动、装满度）

**环境**：风（吹动什么、往哪吹）｜光（色温、方向、云影移动）｜水（涟漪、雨丝斜度、溅起）｜尘雾云（飘移速度）｜背景陪角只做反应不抢主动作

## 示例 A（人物，双主体）

先按五维想，最后一行就是成品。

> ① 主体｜人物。主体一＝小男孩（左，朝右，站立，占画面左三分之一）；主体二＝小女孩（右，朝左，迈步中，占右侧三分之一）。
> ② 动作｜男孩头向左转并下巴点一下，右臂抬至肩高、小臂左右摆两下、手腕放松，左手把小黄花抬到胸前，原地换重心两步；女孩头侧转约 45 度，右手在脸侧挥两下、左手扶裙摆，朝男孩小跑两步后收脚站定；草地被踩下后回弹，藤蔓叶子轻摆。
> ③ 效果｜两人间距缩短半步；辫子与裙摆摆起后回位；表情由平常笑转为张嘴大笑；单看动作即可读出「打招呼」。
> ④ 节奏｜5 秒。0-1s 转头抬臂；1-3.5s 各自挥两下、女孩跑两步；3.5-5s 站定对视保持笑。镜头缓慢推近，起幅全景、落幅中景。关键词 meet 落在 3.5s。
> ⑤ 统一性｜蜡笔彩铅笔触、纸张纹理、天蓝短袖与浅粉连衣裙、白色木门与藤蔓位置均与首帧一致；不新增角色、无文字水印。

成品：

> → 视频提示词：以首帧为准，16:9，5 秒。小男孩转头看女孩、下巴点一下后眉毛扬起张嘴笑，右臂抬至肩高摆两下、左手把一朵小黄花拿到胸前，原地换重心两步；小女孩头侧向男孩、眼睛弯成月牙张嘴笑，右手在脸侧摆两下、左手扶裙摆，朝男孩小跑两步后站定；草被踩下回弹、藤蔓叶子轻摆。镜头缓慢推近，起幅全景落幅中景。保持蜡笔彩铅质感与纸张纹理，人物服装、比例与场景布局与首帧完全一致。负面：纯平涂，光滑无笔触，写实照片，3D渲染，皮克斯风格，赛璐璐上色，镜头剧烈晃动，主体变形换装，多长手脚，手指与五官畸变，画面杂乱，出现文字水印签名。

## 示例 B（植物，无表情）

> ① 主体｜植物。主体一＝一株嫩芽（居中，朝上，生长中，占画面中下三分之一）；主体二＝无。首帧：土面微微隆起，芽尖尚未露头。
> ② 动作｜芽尖顶起土粒，向上抽长约半寸（分两段顿挫，先顶后停再顶），子叶由贴合转为张开约 30 度，茎秆轻微抖颤一次；周围土粒被顶开、向两侧滚落，表层碎土松动下沉。
> ③ 效果｜土面裂开一道细缝并拱起小丘；芽尖顶端高光上移半寸；露出的子叶边缘带一点泥土；单看画面即可读出「破土」。
> ④ 节奏｜5 秒。0-1s 土面隆起；1-3.5s 分两次顶出、子叶张开；3.5-5s 茎秆抖动后停住。镜头固定，仅轻微缓推，起幅中景、落幅近景。
> ⑤ 统一性｜蜡笔彩铅笔触、纸张颗粒、土壤色与周边草叶位置与首帧一致；不新增角色、不加任何五官、无文字水印。

成品：

> → 视频提示词：以首帧为准，16:9，5 秒。一株嫩芽从微微隆起的土面顶出，芽尖分两次向上抽长约半寸，子叶由贴合张开约 30 度，茎秆轻微抖颤一次；土粒被顶开向两侧滚落，土面裂开细缝、拱起小丘，芽尖高光上移。镜头固定并轻微缓推，起幅中景落幅近景。保持蜡笔彩铅质感与纸张纹理，土壤色、草叶位置与首帧完全一致。负面：纯平涂，光滑无笔触，写实照片，3D渲染，皮克斯风格，赛璐璐上色，镜头剧烈晃动，主体变形换装，多长手脚，手指与五官畸变，画面杂乱，出现文字水印签名。

## 常见错与改法

| 错法 | 为什么不行 | 改法 |
| --- | --- | --- |
| 「植物开心地摇叶子」 | 植物没有表情 | 「叶片张开约 30 度并轻轻抖颤一次」 |
| 「男孩挥手」 | 缺四要素 | 补方向、幅度、次数、用时 |
| 首帧躺着，动作写「站起来走」 | 与首帧姿态断层 | 从躺起：先撑手、再跪起、最后站 |
| 「画面很温馨」 | 空词 | 写光影与动作：暖色侧光打在脸颊、嘴角抬起 |
| 一镜里出现下一镜的动作 | 串镜 | 只保留本句含义 |
| 视频里多出一个绘图提示词没写的角色 | 视频在重画首帧 | 删掉，或先回绘图提示词把角色补上再写视频 |
| 句子只说「举起」，成品写「举起又转了个圈」 | 加了句子之外的动作 | 只保留能读出本句的那一段 |
| 成品超过 260 字 | 模型抓不住重点 | 删副动作与环境回应，只留主动作 + 一句反馈 + 一句统一性 |

## 自检（逐条通过才写进成品）

A 主体类型是否明确、主次是否分清、朝向与首帧姿态是否接得上？
B 每个动作是否都有方向、幅度、次数、速度？
C 剪掉首帧单看动作，能否读出这句英文的意思？
D 5 秒内是否具备起势—主动作—收势三段？主动作完成时是否早于朗读结束，且朗读后仍留有 0.7 秒以上的画面运动？
E 是否漏写环境回应或物理反馈？
F 统一性固定项与负面串是否齐全？
G 出现的主体、道具、场景，是否都能在上一行绘图提示词里找到？
H 有没有写出这句英文没有的结果、没有的动作、没有的角色？
I 折算或实测的朗读时长，是否被视频时长连同收势余量完整覆盖？不覆盖时是否先改短句子，而不是硬拖动作或延长视频？
